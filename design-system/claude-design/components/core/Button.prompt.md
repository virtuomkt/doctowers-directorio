Pill-shaped button used for primary actions ("Buscar", "Directorio") and dark secondary chips ("Consultorios disponibles").

```jsx
<Button variant="primary" size="md">Buscar</Button>
<Button variant="dark">Consultorios disponibles</Button>
<Button variant="secondary">Cancelar</Button>
```

Variants: `primary` (teal fill), `dark` (navy fill, used on hero pills), `secondary` (white with border), `ghost` (text-only). Sizes: `sm`, `md`, `lg`. Always fully pill-shaped (`--radius-pill`) — DocTowers never uses square or lightly-rounded buttons.
